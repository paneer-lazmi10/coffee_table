**Problem Statement**
- To design a simple game of cricket in numerical form 
- To  play against a computer that uses 
   - Randomised output as the player.
- Use user defined functions

**Scope of the Project**
- To understand the working of:
  1. Different utilised modules
  2. User defined functions 
  3. utilisation of conditional statements
  4. Proper utilisation of loops
  5. Array operations

**Target Users**
- Cricket Enthusiasts
- Beginner Coders
- Combination of the above mentioned.

**High Level Features**
1. Random module
2. Array Module
3. Validating input in integer inputs
4. User Defined functions
5. Nested loops
